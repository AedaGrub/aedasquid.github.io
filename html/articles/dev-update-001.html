Dev Update #1: What Is This?

Posted on 9th February 2025

What is born in autumn?

It is a fake narrative-driven game for DM5001 Web Design 24S2. It was made for the sole purpose of figuring out what it takes to build a game landing page, and realising how much more there is to do.

Firstly, the website does not use javascript or python, relying only on HTML, CSS, and Bootstrap. Additionally, there is no database for pagination queries, thus each "page" in the devBlog section is actually just another HTML file.

All the illustrations were by Bastien Grivet from his artstation at artstation.com/grivetart. Because there is no license to use his work, this website cannot be used for anything outside of educational purposes.
